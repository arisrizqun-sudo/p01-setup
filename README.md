## Menjalankan Game

Pastikan Python sudah terpasang, lalu jalankan:

```powershell
.\.venv\Scripts\python.exe hello.py
```

Tekan `Space` atau klik mouse untuk membuat burung terbang. Hindari pipa dan tekan `Enter` setelah game over untuk mengulang.
